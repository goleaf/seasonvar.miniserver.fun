# Архив планов и подтверждений

Каталог хранит полные исторические тела, которые больше не должны разрастаться
в едином `docs/plans/current-task-plan.md`. Архивные файлы не являются вторым
реестром активных задач: актуальные owner/status/evidence находятся только в
соседнем current plan.

- [`2026-07-26-shared-main-workflow-evidence.md`](2026-07-26-shared-main-workflow-evidence.md)
  — lossless снимок накопленного current plan перед активацией Task 102.

  `181ee22258c05ae5a99bd6e8d5117e859b1b3b475d1397c8cffdb3ff90776a49`.
  После переноса изменены только 176 относительных Markdown link targets на
  один дополнительный уровень `../`; проверяемый SHA-256 архивного файла —
  `a12519c9cc789dcd0ed7e740c15fb43df8ac6f1f9cad39d82045eb40d4b2ea9e`.
  Весь текст, порядок и полные исторические/параллельные task bodies, включая
  незавершённые evidence Tasks 98/100/101, сохранены без их присвоения
  Task 102.

Новые завершённые подробные подтверждения добавляются отдельными датированными
Markdown-файлами и связываются из current registry. Старые записи не
сокращаются и не удаляются ради уменьшения текущего файла.
