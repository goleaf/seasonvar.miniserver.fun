# Repository Modernization Completion Plan

> **Execution rule:** this is a living plan for the already approved
> master-prompt. Continue task-by-task without pausing for routine approval.

**Goal:** завершить production-grade modernization Seasonvar repository,
сохранив public/data/runtime contracts и доказав результат полными gates.

**Architecture:** existing canonical requirements, domain services, policies,
class-based Livewire pages, passive Blade, CSS-first Tailwind and importer
boundaries remain authoritative. Every behavioral pass uses RED/GREEN TDD;
every maintenance pass records compatibility, rollout and rollback before
manifest/lock changes.

**Stack:** PHP 8.5, Laravel 13, Livewire 4.3+, Tailwind CSS 4.3+, Vite 8,
PHPUnit 12, Larastan/PHPStan, Rector, Pint, Playwright.

## Global constraints

- Existing `main` only; no branch/worktree/PR branch.
- Preserve unrelated untracked audit image.
- Keep one public Seasonvar importer; never import/store complete video.
- Additive/reversible migrations only; no production DML without explicit
  backup/writer evidence.
- ru/en and all route/API/cache/permission/premium/region/legal/PWA/player
  contracts remain compatible unless a canonical requirement is explicitly
  updated first.
- No Volt, `@php`, DB/model/service calls in Blade, inline CSS/business JS,
  direct `env()` outside config, fake integration or placeholder content.
- No new production dependency without an explicit decision record.
